title: Settings
description: Set up your queue, repositories, review, appearance, notifications, AI tools and updates.
order: 13
---

Open Settings with <Kbd keys="⌘ ," />. Settings has eight tabs. Queue & briefings sets which PRs the queue ignores and when Gnosis writes briefings. Repositories sets the defaults for each repository, and its local clone. Review sets how explanations are written, for example <Setting name="Parallel review" section="Review" />. Appearance sets the theme, the code font and code intelligence. Notifications sets which events notify you, and the menu bar icon. Integrations sets up Claude Code and Codex, preloading and the GitHub cache. Updates sets the <Setting name="Update channel" section="Updates" />: Stable or Pre-release. Diagnostics shows the sync health and conflict statistics.
