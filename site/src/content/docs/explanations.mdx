---
title: Explanations
description: Generate a guided explanation of a PR, with sections, diagrams and interactive explainers.
order: 7
---

An explanation is a guided walkthrough of a PR that Claude Code or Codex writes on your computer. It puts the changes in a reading order, in sections, each with its part of the diff. Choose a style: Concise, In Depth, Educational or Custom. Reduce noise hides changes that do not need review. Focused sections <Prerelease /> show only the relevant slices of each file, and list the code outside the explanation at the end. You can choose the model and reasoning effort for each explanation <Prerelease />. Explanations can include diagrams and interactive explainers. Press <Kbd keys="←" /> and <Kbd keys="→" /> to move between sections.
