---
title: Code intelligence
description: Breadcrumbs, whole functions, moved code and quiet changes in diffs.
order: 11
---

Gnosis reads the structure of the code in a diff. Breadcrumbs show the function or class of the line that you read, and you can click them to go there. When a function or class is short, Gnosis can show all of it, not only the changed lines. It finds code that moved, so a moved function is not shown as a deletion and an addition. Press <Kbd keys="w" /> to show or hide quiet changes: whitespace, formatting and comments. Turn these on or off with <Setting name="Show code structure in diffs" section="Appearance" />.
