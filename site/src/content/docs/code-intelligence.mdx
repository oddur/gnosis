Gnosis reads the structure of the code in a diff with tree-sitter. It knows the functions, methods and classes around each change. It uses this structure to show where a change is, to show more of the code around it, and to find code that moved.

## When to use code intelligence

- Use **breadcrumbs** and the **outline** to know where you are in a large file.
- Use **Show whole function** when a hunk does not show enough of the function to understand it.
- Use **quiet changes** to hide changes that do not change behavior, such as formatting.

Code intelligence works for TypeScript, TSX, JavaScript, Rust, Go, Python, Java, C#, JSON and YAML. Quiet changes and moved code also use it, and follow the language settings.

## Breadcrumbs

Each hunk header has a breadcrumb of the definitions around the hunk, for example `impl StoreBridge › fn save`. A long chain shows the two innermost parts. The file header above already names the file, so the file name is only in the tooltip.

The page breadcrumb at the top of the view is different. It shows the PR, the tab and the file. Select a part of it to go there. Some parts have a menu, so you can choose a different item.

## Show the whole function

Each hunk names the function or class around it. Select **Show whole function** (or class, or method) to see all of it, not only the changed lines.

When a short function or class needs at most 10 more lines above and below the change, Gnosis shows all of it automatically. A rail beside the line numbers marks these lines. You can collapse them on any hunk.

## The outline

The outline lists the functions and classes that each file changes. Each symbol is marked as added, modified or removed, and has its own Viewed tick. Use the outline button to show or hide the outline.

## Moved code

When a PR moves a function to a different place, Changes keeps both copies and notes the move on each. The new copy says where it came from, for example "Moved from src/queue.ts:22", and the old copy says where it went. The note also tells you how many lines changed in the move, and has a link to the other copy. Lines that did not change are dimmed, so the edits stand out.

## Quiet changes

Quiet changes are lines that change only whitespace, formatting, comments or imports. Gnosis can collapse them, so you read the changes that matter.

- Press <Kbd keys="w" /> to show or hide all quiet changes at the same time.
- To choose which kinds to hide, open **Diff appearance**. Under **Quiet changes**, select **Hide whitespace-only changes**, **Hide formatting-only changes**, **Hide comment-only changes** or **Hide import-only changes**.

These choices apply to all diffs.

## Settings

Turn code intelligence on or off in <Setting name="Show code structure in diffs" section="Appearance" />. Turn the automatic whole function on or off in <Setting name="Show the whole function or class when it’s short" section="Appearance" />. You can also turn off single languages there.

For explanations, <Setting name="Simplify import changes" section="Review" /> condenses changes that touch only imports.
