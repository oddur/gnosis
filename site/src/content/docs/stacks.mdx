A stack is a chain of PRs where each PR builds on the one below it. Gnosis finds stacks and shows them in the queue and on a stack overview. Use the scope switcher to see the whole stack or one PR in it. Changes can show the combined diff of the stack, or the diff of each PR. The merge plan shows the order in which the PRs can merge, and the conflicts that each step can cause.
