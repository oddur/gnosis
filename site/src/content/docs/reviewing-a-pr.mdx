---
title: Reviewing a PR
description: Read a PR on its Summary, Changes, Commits, Checks and Local notes tabs.
order: 4
---

A PR opens on its Summary tab. Summary shows the description, the timeline of comments and reviews, the people and labels, and whether the PR is ready to merge. Changes shows the diff, with a file tree and a Viewed checkbox for each file and folder. Press <Kbd keys="d" /> to switch between split and unified diffs. Commits shows the diff of each commit. Checks shows the CI workflow as a graph, with the steps of each job; you can run a failed job again from there. Local notes keeps private notes about the PR on your computer, with the code they refer to.
