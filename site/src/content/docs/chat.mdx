title: Chat
description: Ask questions about a PR, an explanation section, or a file.
order: 8
---

Chat lets you ask Claude Code or Codex about the PR that you read. You can chat about the whole PR, about one section of an explanation, or about one file in Changes. Press <Kbd keys="c" /> to open chat for the current section or file. Answers can cite lines in the diff. In Settings, choose the model for each place that has chat, and how much context it gets.
