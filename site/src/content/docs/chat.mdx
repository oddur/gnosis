Chat lets you ask Claude Code or Codex about the PR that you read. The chat opens in a panel beside the code. Answers can cite lines of the PR, and you can open those lines from the answer.

## When to use chat

- Use chat beside an **explanation section** to ask about the change that the section explains.
- Use chat beside a **file** to ask about one file in Changes, Commits or the Summary feedback.
- Use chat when the code is not clear and the explanation does not answer your question.

Chat needs Claude Code or Codex on your computer. See [Getting started](/docs/getting-started/#set-up-an-ai-tool).

## Open chat

1. Open an explanation section, or a file in Changes.
2. Press <Kbd keys="c" />. If the chat is open already, <Kbd keys="c" /> puts the cursor in it.
3. Type your question and press <Kbd keys="Enter" /> to send it. Press Shift+Enter for a new line.

## Ask about selected code

1. Select lines in the diff or in an answer.
2. Select **Ask about this**.
3. The selected code shows above the question field. Type your question and send it.

To remove the selected code before you send, select the remove button on it.

## Choose the model and the context size

The chat panel has a model menu and a **Context** menu.

- **Model**: choose a Claude or Codex model for the next question. The section chat and the file chat each keep their own model.
- **Context**: choose how much of the PR each question carries: 32k, 64k (the default) or 128k tokens. One size applies to all chats.

Gnosis remembers these choices for the next time.

## What Gnosis sends

Claude Code and Codex run on your computer, but the models run at Anthropic or OpenAI. Each question sends your question, the selected code, the PR's title and description, the diff of the file or section, related files, and more of the PR's diff, up to the context size. A larger context size sends more of your code. Explanations send code too. See [Explanations](/docs/explanations/#what-gnosis-sends).

## While the answer comes

- Select **Stop answer** to stop the answer.
- You can write your next question while the answer comes. Send it when the answer is complete.
- Drag the edge of the panel to make it wider or narrower.
- Press <Kbd keys="Esc" /> to close the chat.

## Read the answer

An answer can cite a file or lines of the PR. Select a citation to open those lines. A citation of a file that is not in the PR shows as plain text.
