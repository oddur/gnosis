Gnosis has keyboard shortcuts for most work. This page lists the main shortcuts, by the place where they work.

## How to read this page

- The keys are the macOS keys. On Windows and Linux, use Ctrl for ⌘, and Alt+← and Alt+→ to go back and forward.
- Single-key shortcuts do not work while you type in a text field, or while a dialog is open.
- In an explanation, press <Kbd keys="?" /> to see the most used shortcuts. The overlay leaves out the tab, history, queue, Overview, feedback and diagram keys.

## Everywhere

| Keys | Action |
| --- | --- |
| <Kbd keys="⌘ K" /> | Open the command palette |
| <Kbd keys="⌘ ," /> | Open Settings |
| <Kbd keys="Esc" /> | Close a dialog or overlay |
| <Kbd keys="⇧ F10" /> | Open the menu of a PR or stack |

## Tabs and history

| Keys | Action |
| --- | --- |
| <Kbd keys="⌘ T" /> | Open a new home tab |
| <Kbd keys="⌘ W" /> | Close the tab |
| <Kbd keys="⌘ ⇧ T" /> | Reopen the last closed tab |
| <Kbd keys="⌃ Tab" /> | Go to the next tab |
| <Kbd keys="⌃ ⇧ Tab" /> | Go to the previous tab |
| <Kbd keys="⌘ 1–9" /> | Go to the tab at that position. ⌘9 goes to the last tab. |
| <Kbd keys="⌘ [" /> | Go back |
| <Kbd keys="⌘ ]" /> | Go forward |

## Queue

| Keys | Action |
| --- | --- |
| <Kbd keys="j" /> <Kbd keys="↓" /> | Select the next PR |
| <Kbd keys="k" /> <Kbd keys="↑" /> | Select the previous PR |
| <Kbd keys="Enter" /> | Open the selected PR |
| <Kbd keys="/" /> | Search the queue |
| <Kbd keys="z" /> | Snooze the selected PRs |
| <Kbd keys="⌘ A" /> | Select every PR in the list |
| <Kbd keys="⌘ Space" /> | Add the focused PR to the selection, or remove it. ⌘-click does the same, and macOS often uses ⌘ Space for Spotlight. |
| <Kbd keys="⌘ \" /> | Show or hide the queue sidebar |

Shift-click, or Shift+↑ and Shift+↓, selects a range of PRs.

## Overview

| Keys | Action |
| --- | --- |
| <Kbd keys="j" /> <Kbd keys="k" /> | Select the next or previous row |
| <Kbd keys="Enter" /> | Open the selected row |
| <Kbd keys="a" /> | Do the row's action, for example Merge, Review, Reply, Remind or Close PR |
| <Kbd keys="z" /> | Snooze the row |

## PR actions

| Keys | Action |
| --- | --- |
| <Kbd keys="⌘ ⇧ M" /> | Open the merge confirmation |
| <Kbd keys="⌘ ⇧ U" /> | Open the Update menu |
| <Kbd keys="⌘ ⇧ V" /> | Review the PR, reply to feedback, or request a review |

## Summary

| Keys | Action |
| --- | --- |
| <Kbd keys="j" /> <Kbd keys="k" /> | Go to the next or previous item in the timeline. Outside the timeline, go to the next or previous PR. |
| <Kbd keys="Esc" /> | Go back |
| <Kbd keys="n" /> | Go to the next unresolved thread |
| <Kbd keys="r" /> | Reply |
| <Kbd keys="e" /> | Resolve the thread |
| <Kbd keys="u" /> | Mark the item as unread |

## Diffs

| Keys | Action |
| --- | --- |
| <Kbd keys="d" /> | Switch between split and unified diffs |
| <Kbd keys="u" /> | Show the unified diff |
| <Kbd keys="s" /> | Show the split diff |
| <Kbd keys="w" /> | Show or hide quiet changes: whitespace, formatting, comments and imports |
| <Kbd keys="c" /> | Open chat for the current section or file, or put the cursor in it |
| <Kbd keys="v" /> | Mark the file or symbol selected in the file tree as viewed <Prerelease /> |
| <Kbd keys="n" /> | In Changes, go to the next symbol that is not viewed <Prerelease /> |
| <Kbd keys="⇧ N" /> | In Changes, go to the previous symbol that is not viewed <Prerelease /> |

## Explanations

| Keys | Action |
| --- | --- |
| <Kbd keys="?" /> | Show the keyboard shortcut overlay |
| <Kbd keys="→" /> <Kbd keys="j" /> | Go to the next section |
| <Kbd keys="←" /> <Kbd keys="k" /> | Go to the previous section |
| <Kbd keys="g g" /> | Go to the change overview |
| <Kbd keys="G" /> | Go to the last section |
| <Kbd keys="1 – 9" /> | Go to a section by its number |

## Diagrams

These keys work in the expanded D2 or Mermaid viewer. See [Explanations](/docs/explanations/#diagrams-and-interactive-explanations).

| Keys | Action |
| --- | --- |
| <Kbd keys="+" /> | Zoom in (= also works) |
| <Kbd keys="-" /> | Zoom out |
| <Kbd keys="0" /> | Fit the diagram to the view |
| <Kbd keys="1" /> | Show the diagram at its actual size |

## Resolving conflicts

These keys work in the Conflicts view. See [Resolving conflicts](/docs/resolving-conflicts/).

| Keys | Action |
| --- | --- |
| <Kbd keys="j" /> <Kbd keys="k" /> | Go to the next or previous conflict |
| <Kbd keys="a" /> | Use the proposal and go to the next conflict that needs you |
| <Kbd keys="1" /> | Keep the PR's change |
| <Kbd keys="2" /> | Keep the base branch's change |
| <Kbd keys="3" /> | Keep both changes |
| <Kbd keys="u" /> | Undo the choice on the current conflict, or the last <Kbd keys="a" /> |
| <Kbd keys="v" /> | Compare with the PR, the base branch, or both |
| <Kbd keys="g" /> | Turn on Review Merged-only files myself |
| <Kbd keys="m" /> | Mark the file as reviewed and open the next file |
| <Kbd keys="n" /> <Kbd keys="p" /> | Go to the next or previous file |
| <Kbd keys="⌘ ↵" /> | Open the Review and push confirmation. It does not push. |
| <Kbd keys="Esc" /> | Close the Conflicts view |
