Gnosis is a desktop app for GitHub code review. Install it on macOS from the download on [gnosis.to](/#download), or with Homebrew: `brew tap oddur/gnosis && brew install --cask gnosis`. When Gnosis opens for the first time, the Set up Gnosis wizard asks what your queue must show and which repositories to watch. Connect GitHub with OAuth or a token. Explanations and chat use Claude Code or Codex on your computer. Gnosis finds these tools and shows a setup guide when it cannot find one. Then a guided tour shows the Review Queue, a PR, its changes, and the menu bar. To see the tour again, use <Setting name="Show walkthrough" section="Integrations" />.
