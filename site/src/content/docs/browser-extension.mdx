---
title: Browser extension
description: Open GitHub PRs, commits and comparisons in Gnosis from your browser.
order: 15
---

The Gnosis browser extension adds an Open in Gnosis button to GitHub. It works in Chrome, Edge and Firefox, on PR, commit and compare pages. The button opens the page in Gnosis with a `gnosis://` link. Install it from `extensions/browser` in the Gnosis repository; its README has the steps.
