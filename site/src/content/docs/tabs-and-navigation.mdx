---
title: Tabs & navigation
description: Open several PRs and views in tabs, go back and forward, and open Gnosis from links.
order: 3
---

Each Gnosis window has workspace tabs, so you can keep a PR, a stack and your queue open at the same time. Press <Kbd keys="⌘ T" /> to open a tab and <Kbd keys="⌘ W" /> to close it. Drag a tab to move it, and right-click it for more actions. Gnosis keeps a history in each tab: press <Kbd keys="⌘ [" /> to go back and <Kbd keys="⌘ ]" /> to go forward. The command palette (<Kbd keys="⌘ K" />) finds PRs, views and commands. Links that start with `gnosis://` open a PR, a stack, a conflict or a queue view directly. The browser extension makes these links from GitHub pages.
